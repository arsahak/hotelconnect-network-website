# HotelConnect Network

Website for HotelConnect Network, a private B2B platform where boutique hotels and verified suppliers find each other. It covers compliance, tenders, jobs and group purchasing.

## Getting started

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

To build and run the production version:

```bash
npm run build
npm start
```
